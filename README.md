# PigFarmTech: Sistema Inteligente de Gestión para Granjas Porcinas

## Descripción del Proyecto
Este proyecto consiste en el desarrollo de un sistema digital web diseñado para registrar, monitorear y gestionar de manera eficiente la información de los animales en una granja porcina. Su propósito principal es solucionar el descontrol del registro manual, facilitando el seguimiento preciso de la alimentación, el crecimiento, el plan de vacunación y el estado general de salud de los cerdos para optimizar la productividad y mejorar la toma de decisiones oportunas.

## Tecnologías Usadas (Stack Tecnológico Sugerido)
* **Frontend:** HTML5, CSS3, JavaScript (Para una interfaz web limpia y fácil de usar por los porcicultores)
* **Backend:** Java (Orientado a la lógica del negocio del sistema)
* **Base de Datos:** MySQL (Para el almacenamiento estructurado de los datos de los porcinos)

## Alcance del Sistema (MVP)
### Lo que Incluye:
* **Registro de porcinos:** Control de edad, peso, raza y fecha de nacimiento.
* **Control de alimentación:** Registro diario del consumo.
* **Control sanitario:** Registro detallado de vacunas y medicamentos aplicados.
* **Evolución:** Seguimiento del crecimiento y desarrollo de los animales.
* **Reportes:** Generación de reportes básicos de producción basados en datos.

### Lo que Excluye:
* Automatización con sensores IoT reales.
* Integración con sistemas externos de venta o comercialización masiva.
